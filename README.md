# 歌单导入 · Salt Player for Windows

将移动端椒盐音乐导出的 **TXT歌单文件** 导入 SPW 本地歌单

源码仓库：[aikavvak12una/SPW-playlistimport](https://github.com/aikavvak12una/SPW-playlistimport)

## 安装和使用

1. 在播放器中将电脑上的音乐文件加入曲库，完成扫描
2. 打开 **创意工坊 → 模组管理 → 导入模组**，选择 `spw.playlistimport.spmod`
3. 启用模组，授予必要权限
4. 打开 **歌单导入 → 配置 → 选择歌单文件**
5. 窗口只显示未找到、同名不唯一或不可读的歌曲。点击异常歌曲行可指定曲库中的文件
6. 填写歌单名称，点击 **创建歌单**，检查数量后 **确认创建**。未处理的异常记录会自动跳过。
